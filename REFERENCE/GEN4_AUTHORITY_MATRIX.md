# Gen-4 Authority Matrix

| Capability | Owner | OperatorSystem |
|---|---|---|
| Artifact validation | Sandbox/Policy | requests only |
| Deployment approval | ApprovalGateway + human | cannot approve |
| Spending/treasury | Treasury | no access |
| Credentials | Credential authority | scoped lease request |
| Network/customer communication | Policy + human | prohibited |
| Source mutation | Evolution/Approval | prohibited |
| Incident stop | Human/Policy | may request pause |
| Audit/provenance | Memory/Audit | append evidence |

Human constitutional sovereignty is permanent and overrides every automated path.

OperatorSystem may request, validate, stage, observe, pause, and propose
rollback. It may not decide approval, policy, treasury, identity, signing,
egress, customer communication, source mutation, or constitutional changes.
