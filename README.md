# Autark Brain (autark-brain)

This repository contains the permanent historical record, architectural decisions (ADRs), audit reports, and engineering standards for the Autark organism.

## Structure
- **/AUDITS**: Mechanical evidence from Chaos testing, E2E validation, and Performance benchmarking.
- **/RELEASES**: Official release manifests, known limitations, and roadmap documentation (e.g. `Gen-1 Release`).
- **ENGINEERING_STANDARDS.md**: The mechanical operating principles governing organism development.

By strictly segregating this repository from the executable kernel, we maintain a clean and verifiable history of the organism's evolution.
